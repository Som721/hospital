# Hospital Management System

Hospital Management System is a Java-based application developed to automate and manage hospital operations. The system helps maintain patient records, doctor details, appointments, and billing information through a centralized platform.

## Included Requirements

* Patient Management
* Doctor Management
* Appointment Scheduling
* Billing Management
* Search and View Records
* Menu-Driven Interface
* Dynamic Data Storage using ArrayList
* Object-Oriented Design
* Exception Handling

## Prerequisites

* Java JDK 8 or above
* Any Java IDE (Eclipse, IntelliJ IDEA, NetBeans, VS Code)

## Run the Project

1. Download or clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Open the project in your Java IDE.

3. Compile the source code:

   ```bash
   javac HospitalManagementSystem.java
   ```

4. Run the application:

   ```bash
   java HospitalManagementSystem
   ```

## Features

* Add Patient Records
* View Patient Details
* Search Patient Information
* Delete Patient Records
* Add Doctor Information
* View Doctor Details
* Book Appointments
* Generate Bills
* View Billing History
